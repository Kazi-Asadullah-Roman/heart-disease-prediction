
# Heart Disease Prediction Using Machine Learning - Proposal Branch

## 1. Project Overview

This project focuses on predicting the presence of heart disease using machine learning classification algorithms.

The project uses clinical attributes of patients to investigate the performance of different classification models.

## 2. Research Objective

The main objective is to compare different machine learning classification algorithms and investigate their effectiveness in predicting heart disease.

## 3. Dataset Information

- Dataset Name: UCI Heart Disease Dataset
- Subset: Cleveland
- Number of Records: 303
- Number of Predictive Attributes: 13
- Source: UCI Machine Learning Repository

Dataset Link:
https://archive.ics.uci.edu/dataset/45/heart

## 4. Machine Learning Algorithms

- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier

## 5. Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix
