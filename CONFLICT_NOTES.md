
# Merge Conflict Documentation

## 1. Conflict Description

A merge conflict occurred in the README.md file while merging the proposal branch into the main branch.

## 2. Reason for the Conflict

Both branches modified the same heading in README.md with different text.

**Main Branch:**

# Heart Disease Prediction Using Machine Learning - Main Branch

**Proposal Branch:**

# Heart Disease Prediction Using Machine Learning - Proposal Branch

Git could not automatically decide which version should be kept.

## 3. Conflict Resolution Process

The conflict was resolved manually using Visual Studio Code.

The conflicting lines and Git conflict markers were removed.

The original project heading was retained:

# Heart Disease Prediction Using Machine Learning

## 4. Verification

After resolving the conflict, the README.md file was saved.

The resolved file was staged and committed using Git.

Finally, the updated proposal branch was pushed to GitHub.
